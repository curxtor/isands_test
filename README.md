# Тестовое задание: SPA страница сравнения товаров (Vue 3 + Pinia + TypeScript)

## Описание проекта

Данное приложение реализует страницу сравнения товаров (смартфонов) для SPA-приложения.  
Использован стек: Vue 3 с Composition API, Pinia для управления состоянием, TypeScript.  
UI-библиотеки не применялись — все компоненты и стили написаны вручную.

---

## Функционал

1. **Вывод сравнения смартфонов** с базовыми характеристиками: производитель, год релиза, диагональ экрана, страна производства, объем памяти, частота обновления, NFC, ESIM, беспроводная зарядка, стоимость.

2. **Настройка количества отображаемых товаров для сравнения** (от 2 до 6).

   - Значение задаётся через фильтр «Отобразить товары».
   - Количество товаров может быть ограничено общим числом доступных смартфонов.

3. **Всплывающее окно замены товара** по клику на иконку возле каждого смартфона:

   - Отображает остальные не показанные смартфоны.
   - Если товаров для замены больше 3 — появляется поле поиска и полоса прокрутки.
   - Позволяет заменить отображаемый товар на выбранный из списка без перезагрузки страницы.

4. **Чекбокс «Показать различия»** фильтрует строки сравнения, показывая только те характеристики, которые отличаются между отображаемыми товарами.

---

## Структура проекта

- `App.vue` — основной компонент страницы сравнения
- `stores/smartphones.ts` — Pinia store, содержит логику работы со смартфонами, фильтрами, заменами и состоянием отображения
- `types/SmartphoneTypes.ts` — интерфейсы TypeScript для описания модели данных смартфона
- `assets/` — изображения и иконки (например, true.svg и false.svg для отображения поддерживаемых функций)
- `assets/styles/style.css` — основные стили страницы

## Запуск проекта

1. Клонировать репозиторий
2. Установить зависимости:
   ```bash
   npm install
   ```
3. Запустить dev сервер

```bash
npm run dev
```

4. Открыть в браузере указанный адрес (обычно http://localhost:3000)

## Ключевые моменты реализации

- Pinia store содержит все смартфоны, отображаемые товары, фильтры и логику замены

- Используется реактивность Vue и computed для динамического обновления UI

- Строки сравнения выводятся с учётом фильтра «Показать различия» через метод shouldShowSpec

- Всплывающие окна реализованы с помощью условного рендеринга и управления классами для открытия/закрытия

- Поиск в списке замены товаров фильтрует результаты в реальном времени

- Поддерживается адаптивная вёрстка (при желании можно расширить)
